# Network Diagnostic & Stress Testing Tool

Aplikasi desktop berbasis JavaFX yang mengintegrasikan berbagai modul diagnostik jaringan dan uji ketahanan server ke dalam satu antarmuka terpadu.

## 🛠️ Fitur Utama
* **Ping & Traceroute**: Pengujian konektivitas, latensi, dan rute jaringan.
* **Port Scanner**: Pemindaian status port TCP secara masif & multithreaded.
* **Stress Test**: Simulasi beban trafik HTTP masif untuk menguji ketahanan web server.
* **Unified Export Report**: Ekspor hasil pengujian dari 3 modul sekaligus beserta catatan auditor ke file `.txt`.

## 🚀 Cara Menjalankan (Portable / EXE)
1. Buka halaman [Releases](../../releases).
2. Unduh file **NDT-Portable.zip**.
3. Ekstrak file `.zip` tersebut.
4. Jalankan **`NetworkDiagnosticTool.exe`** (Tidak memerlukan instalasi Java/JDK pada sistem target).

## 💻 Tech Stack
* **Language**: Java 17
* **Framework**: JavaFX
* **Build System**: Apache Maven
* **Packaging**: jpackage (Portable Windows Binary)
